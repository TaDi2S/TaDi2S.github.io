# Pandas란
- 파이썬의 데이터 분석 오픈소스 라이브러리 중 하나
- 데이터 조작, 정제, 분석, 시각화등을 위한 다양한 기능을 제공
- 주로 행, 열로 이루어진 표 형식의 데이터를 손 쉽게 다룰 수 있도록 설계되어 있다
- numpy를 기반으로 만들어짐
## 설치 및 사용
- 다음 명령어로 설치 가능
```bash
$ pip install pandas
```
- 특정 버전 설치
```bash
$ pip install pandas==1.3.0
```
- 최신 버전 설치
```bash
$ pip install pandas --upgrade
```
- 파이썬에서는 다음과 같이 import하여 사용
```python
import pandas as pd
```
## 특징
1. 데이터 입출력
   - **CSV**, **Excel**, **SQL** 등 다양한 파일 형식과 데이터베이스로부터 데이터를 읽고 쓸 수 있다.
   - 웹 **API**나 **JSON** 형식의 데이터도 손쉽게 처리할 수 있다.
2. 데이터 조작 및 처리
  - **인덱싱**, **슬라이싱**, **필터링**을 통해 원하는 데이터를 선택할 수 있다.
    - **e.g.**: 특정 열만 선택하거나 조건에 맞는 행을 필터링하여 데이터를 분석할 수 있음
  - **결측치 처리**: 결측치 처리 기능을 제공하여 누락된 데이터를 탐지하고 대체하거나 제거할 수 있다.
    - **e.g.**: 결측치가 포함된 데이터를 `fillna()` 메서드를 사용해 평균값으로 대체하거나 `dropna()`를 사용해 결측치를 제거할 수 있음
  - **병합과 연결**: 여러 데이터프레임을 하나로 합칠 수 있다.
    - **e.g.**: 여러 지역의 판매 데이터를 하나의 데이터프레임으로 병합하여 전체 매출을 분석할 수 있음
3. 데이터 분석
  - **그룹화 연산**: 특정 기준으로 데이터를 그룹화하여 집계함수를 적용할 수 있다.
    - **e.g.**: 매출 데이터를 제품별로 그룹화하여 총 매출을 계산하거나, 고객 데이터를 연령대별로 그룹화하여 평균 구매 금액을 계산할 수 있음
  - **시계열 데이터 처리**:  시간 축에 따른 데이터 분석을 지원, 날짜와 시간을 효과적으로 다룰 수 있다.
    - **e.g.**: 일별 매출 데이터를 날짜별로 정렬하여 시계열 분석을 수행하거나, 특정 기간 동안의 추세를 파악할 수 있음
  - **통계 함수 제공**: 평균, 분산 등 기본적인 통계량을 계산할 수 있다.
    - **e.g.**: 데이터프레임의 `describe()` 메서드를 사용해 평균, 중앙값, 표준편차 등의 통계량을 쉽게 확인할 수 있음
## 자료 구조
- 주요 네 가지 자료구조인 Series, DataFrame, Index, MultiIndex를 제공. 
### Series
- 인덱스를 가지는 일차원 배열 자료 구조
- 주로 하나의 속성이나 변수에 대한 데이터를 다룰 때 사용
- 리스트와 유사하지만 인덱스를 사용하여 데이터를 쉽게 참조하고 조작할 수 있도록 설계되어 있음
- 인덱스는 보통 0부터 시작하는 정수형으로 가질 수 있지만 사용자가 명시적으로도 지정 가능
- 개인적으로 dict와 list를 동시에 사용할 수 있는 자료형으로 생각
- 인덱스를 불 규칙한 정수형을 사용했을 때 `loc`를 이용해서 명시적 인덱스를 사용할 수 있고 `iloc`를 이용해 묵시적으로 사용할 수 있다.
- **Series 사용 예시**: 한 사람의 나이나 상품의 가격처럼 단일 특성을 다루는 경우 사용
#### 클래스 구조
```python
class pandas.Series(data=None, index=None, dtype=None, name=None, copy=False, fastpath=<no_default>)
```
- **data**:
  - Series에 저장할 데이터
  - 배열, 리스트, 튜플, 딕셔너리등이 들어 올수 있다.
  - 만약 딕셔너리 데이터가 들어온다면 key값이 index가 된다.
- **index**:
  - 데이터에 대응하는 index, 지정하지 않으면 0 부터 시작하는 정수가 할당된다.
  - data의 값이 딕셔너리 형태라면 key값이 인덱스로 설정된다.
  - data의 값이 딕셔너리 형태인데 index에도 데이터를 넣어준다면 index에 넣어준 데이터를 key로 하여 data에 매핑시킨 뒤 data에 없는 index의 값들은 NaN을 넣어준다.
- **dtype**:
  - 데이터의 자료형을 명시적으로 지정
  - 입력하지않으면 자동으로 추론함.
- **neme**:
  - Series객체에 이름을 부여할 수 있다.
- **copy**:
  - True로 설정하면 깊은 복사, False로 설정하면 약한 복사를 한다.
#### e.g.
- 기본적인 생성:

```python
import pandas as pd

# 기본 Series 생성
s = pd.Series([10, 20, 30, 40, 50])
print(s)
```

- 실행 결과

```python

0    10
1    20
2    30
3    40
4    50
dtype: int64
```


- 인덱스를 지정하여 Series 생성:

```python
import pandas as pd

# 인덱스를 지정하여 Series 생성:
s = pd.Series([10, 20, 30], index=['a', 'b', 'c'])
print(s)
```

- 실행 결과

```python
# 실행결과
a    10
b    20
c    30
dtype: int64
```

### DataFrame
- 행 열로 이루어진 2차원 자료 구조
- 표 형태로 이루어진 데이터를 다를 수 있다.
- 각 열(columns)은 서로 다른 데이터 타입을 가질 수 있으며, 행과 열에 인덱스를 부여할 수 있다.
- **DataFrame 사용 예시**: 고객의 이름, 나이, 도시와 같은 여러 속성을 가진 데이터를 다룰 때 사용하며, 하나의 속성만을 다룰 때는 Series를 사용하는 것이 더 적합
#### 클래스 구조

```python
class pandas.DataFrame(data=None, index=None, columns=None, copy=None)
```
- **data**:
  - DataFrame에 저장할 데이터
  - 딕셔너리, 리스트, 배열, 데이터프레임 등이 가능
- **index**:
  - 행에 대한 인덱스
  - 지정하지 않으면 0부터 시작하는 정수형 인덱스가 할당됨
- **columns**:
  - 열에 대한 이름을 지정
  - 지정하지 않으면 기본적으로 0부터 시작하는 정수형 열 이름이 할당됨
- **copy**: 
  - True로 설정하면 깊은 복사를 수행함

#### e.g.

```python
import pandas as pd

data = {
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Age': [25, 30, 35],
    'City': ['Seoul', 'Busan', 'Incheon']
}

df = pd.DataFrame(data)
print(df)
```

- 실행결과

```python

      Name  Age     City
0    Alice   25    Seoul
1      Bob   30    Busan
2  Charlie   35  Incheon

```

### Index
- Series나 DataFrame의 각 축(axis)에 대한 레이블을 관리하는 객체
- 인덱스는 고유하며 변경할 수 없도록 설계되어 있어 데이터의 일관성을 유지하는 데 유용함
- 특정 열을 인덱스로 설정하거나 DataFrame의 인덱스를 초기화할 때 사용

#### 클래스 구조

```python
class pandas.Index(data=None, dtype=None, copy=False, name=None, tupleize_cols = True)
```

- **data**
  - 인덱스에 저장할 데이터
  - 배열과 같은 형태의 1차원 데이터
- **dtype**
  - 출력 인덱스의 데이터 타입'
  - 문자열(str), NumPy의 dtype, 또는 ExtensionDtype 중 하나를 사용할 수 있음.
  - 명시하지 않으면 데이터로부터 추론함.
- **copy**:
  - True로 설정하면 깊은 복사를 수행함
- **name**: 
  - 인덱스 객체에 이름을 부여할 수 있음
- **tupleize_cols**:
  - True로 설정하면 가능한 경우 [MultiIndex](#multiindex)를 생성하려고 시도함
#### e.g.

```python
import pandas as pd

# 기본 DataFrame 생성
s = pd.Series([10, 20, 30], index=['a', 'b', 'c'])
index = s.index
print(index)
```
- 실행결과

```plaintext
Index(['a', 'b', 'c'], dtype='object')
```

### MultiIndex

- 여러 레벨의 인덱스를 가지는 인덱스 객체로, 다차원 데이터를 손쉽게 표현할 수 있도록 설계되어 있음
- DataFrame이나 Series에서 다중 인덱싱을 사용하여 복잡한 데이터를 체계적으로 관리할 수 있음
- 예를 들어, 매출 데이터를 지역별, 연도별, 그리고 제품 카테고리별로 분석할 때 MultiIndex를 사용하면 각 레벨에 따라 데이터를 구분하고 정리할 수 있음
- MultiIndex를 사용하면 데이터의 구조를 더 명확하고 직관적으로 표현할 수 있으며, 다양한 기준으로 데이터를 조회하고 집계하는 작업이 용이해짐

#### 클래스 구조

```python
class pandas.MultiIndex(levels=None, codes=None, sortorder=None, names=None, dtype=None, copy=False, verify_integrity=True)
```

- **levels**: 
  - 각 레벨의 고유한 값 리스트
- **codes**:
  - 각 레벨의 인덱스 위치를 나타내는 코드 리스트
  - 각 레벨에서 값이 나타나는 인덱스 위치를 지정하는 배열
- **sortorder**:-
  -  정렬 순서를 지정함
- **names**:
  - 각 레벨의 이름을 지정함
- **dtype**:
  - 자료형을 명시적으로 지정함
- **copy**: 
  - 메타데이터를 복사 할지 지정함
- **verify_integrity**: 
  - True로 설정하면 데이터의 무결성을 검사함

#### e.g.

```python
import pandas as pd

# MultiIndex 생성
arrays = [['A', 'A', 'B', 'B'], [1, 2, 1, 2]]
multi_index = pd.MultiIndex.from_arrays(arrays, names=('Letter', 'Number'))
print(multi_index)
```

```plaintext
MultiIndex([('A', 1),
            ('A', 2),
            ('B', 1),
            ('B', 2)],
           names=['Letter', 'Number'])
```

## 주요 함수

- `read_csv()`, `to_csv()`

  - CSV 파일의 입출력을 담당함
  - 매개변수로 파일 경로를 입력함
  - **e.g.**:

  ```python
  # CSV 파일 읽기
  df = pd.read_csv('data.csv')
  print(df.head())

  # CSV 파일로 저장
  df.to_csv('output.csv', index=False)
  ```

- `head()`, `tail()`

  - 데이터프레임의 처음 또는 마지막 몇 행을 출력함
  - 매개변수로 출력할 행의 수를 지정할 수 있음
  - **e.g.**:

  ```python
  # 데이터프레임의 처음 5개 행 출력
  print(df.head())

  # 데이터프레임의 마지막 3개 행 출력
  print(df.tail(3))
  ```

- `describe()`

  - 수치형 데이터의 요약 통계량을 보여줌
  - **e.g.**:

  ```python
  # 데이터프레임의 요약 통계량 출력
  print(df.describe())
  ```

- `isnull()`, `dropna()`, `fillna()`

  - 결측치 탐색과 처리에 사용됨
  - **e.g.**:

  ```python
  # 결측치 탐색
  print(df.isnull())

  # 결측치가 있는 행 제거
  df_cleaned = df.dropna()

  # 결측치를 특정 값으로 대체
  df_filled = df.fillna(0)
  ```

- `pivot_table()`

  - 피벗 테이블을 생성하여 다차원적인 데이터를 분석할 수 있음
  - **e.g.**:

  ```python
  # 피벗 테이블 생성
  pivot = df.pivot_table(values='Age', index='City', aggfunc='mean')
  print(pivot)
  ```
